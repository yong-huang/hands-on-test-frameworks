## 判读要点

- RPS 不再随并发增长的档位 = 饱和区；饱和区里 P95 最低的配置 = 最优工作点
- worker 数超过容器 CPU 配额后收益归零甚至回退（上下文切换税）
- GOMAXPROCS 硬压到 1 会人为制造 CPU 瓶颈——真实部署里它是留给容器
  CPU limit 对齐用的（超卖环境不设对齐会抖）
