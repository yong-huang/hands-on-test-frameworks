## 3. 90 天演进路线（按 ROI 排序，全部映射已验证产物）

| 阶段 | 天数 | 动作 | 依据产物 | ROI 依据 |
|:---|:---|:---|:---|:---|
| P1 止血 | D1-15 | flaky 检测隔离上线，主干假红清零 | architect/13_flaky_platform | CI 信用恢复是一切前提 |
| P1 止血 | D1-15 | 质量门禁接入（覆盖率/绿榜/严重缺陷） | architect/03_quality_gate | 零测试执行成本，0.8s 裁决 |
| P2 提速 | D16-45 | 三层流水线 + 冒烟圈选（≤20% 且含 P0） | architect/10_pipeline_tiers | PR 反馈从小时级到 3 分钟 |
| P2 提速 | D16-45 | LPT 分片 + 精准推荐（12 覆盖盲区补齐） | architect/11_shard_scheduler + architect/12_incremental_selector + architect/04_precise_testing | 246 条实测提速 76% |
| P3 体系 | D46-75 | 环境工厂替代端口蔓延；契约矩阵进发布 | architect/16_env_factory + architect/15_contract_matrix | 并发隔离实测 4s；v2 被拦截实证 |
| P3 体系 | D46-75 | 风险策略驱动补测 + 数据工厂 + 自愈定位 | architect/02_risk_strategy + architect/07_data_factory + architect/09_self_healing | 登录 P0 三层裸奔等缺口定向补齐 |
| P4 右移 | D76-90 | 灰度判定 + 合成探针；度量看板进周会 | architect/18_canary_eval + architect/19_synthetic_probe + architect/23_metrics_dashboard | 高频低影响功能交给探针更便宜 |
